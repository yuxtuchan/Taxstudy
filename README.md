# 消費税法 理論暗記ツール

税理士試験（消費税法）の理論を暗記するための、ブラウザだけで動くツールです。
インストール・サーバー不要。`index.html` をブラウザで開けばすぐ使えます。

## 学習モード

| モード | 内容 |
|---|---|
| 全文 | 本文を表示。【】の語句をハイライト。読み上げ（聞き流し）にも対応 |
| キーワード穴埋め | 【】で囲んだ語句が空欄に。タップで答えを表示 |
| ランダム穴埋め | 漢字・カタカナの語句をランダムに隠す（割合 20〜100% を選択） |
| 頭文字 | 語句の1文字目だけを表示（例：`課○○○`） |
| 書き出し | 題名だけを見て本文を書き、原文との差分と正答率を表示 |

学習後に「もう一度／うろ覚え／完璧」で自己評価すると、次の復習日が自動で決まります（間隔反復）。
「今日の復習」から、復習日が来た理論を順番に回せます。

## 問題と項目

本文に「〔1〕国内取引」のような見出しの行がある理論は、開くと項目（〔1〕〔2〕…）の一覧が出ます。
項目を選ぶとその部分だけを解けて、解いたあとに「もう一度／うろ覚え／完璧」で項目ごとの習熟度を付けます。
一覧では、項目ごとの習熟度が色つきの四角で並びます（赤＝もう一度、黄＝うろ覚え、緑＝完璧、灰＝未学習）。

## 今日の復習

復習日が来た項目と、まだ学習していない項目（1日の上限つき・ランクの高い順）が出ます。
上限は「データ」画面の「1日に新しく覚えるカードの数」で変えられます（初期値10枚）。

## 理論の登録

- 「＋追加」から1つずつ登録。覚えたい語句は `【】` で囲みます（選択して「【】で囲む」ボタンでも可）。
- 「データ」画面の「まとめて追加」で、次の形式のテキストを一括登録できます。

```
# 課税の対象｜総則｜A
【国内】において【事業者】が行った……

# 納税義務者｜総則｜A
【事業者】は、……
```

## データの保存

学習データはブラウザ（localStorage）内に保存されます。
機種変更やブラウザのデータ削除に備えて、「データ」画面から JSON で書き出しておいてください。

## 注意

このツールには理論の本文を同梱していません。理論は「データ」画面から読み込むか、「＋追加」で登録してください。
市販の理論テキストの本文は著作物なので、自分の学習用として手元だけで使い、リポジトリなど公開の場所には置かないでください。
